## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/kamrul397/my-portfolio.git
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Visit

```
http://localhost:3000
```
